# BezierWall2D

Unity 2022.3.62f2 的卡通薄墙编辑器，用于正交相机下的俯角 2D 场景。

[完整使用说明](Docs/USER_GUIDE.md)

## 试用示例

1. 在 Unity Hub 里添加此工程，使用 Unity 2022.3.62f2 打开。
2. 在 Project 窗口打开 `Assets/BezierWallDemo/Garden Demo.unity` 查看贝塞尔花园墙，或打开 `Assets/BezierWallDemo/RoundedWall/Terrace Demo.unity` 查看圆角露台墙。
3. 双击场景同目录的草稿 `.asset`，查看参考图和已有描点。圆角露台草稿包含门洞和一排黄铜灯笼。双击 `Terrace Flower Bed Layout.asset` 可编辑闭环花坛。
4. 露台下方展示同一条路径的砖墙与矮石墙。打开 `Style Comparison/Comparison Path Layout.asset`，在「墙体样式」里分别套用 `Brick Wall Style.asset` 和 `Low Stone Wall Style.asset`，再切到「成品预览」。

## 从素材开始

1. 打开 **Tools → 2D 弧形墙编辑器**，把 `Texture2D` 或 `Sprite` 拖到「描点底图」。底图宽度以 Unity 单位计，高度按图片比例计算。
2. 在「路径类型」选择「贝塞尔曲线」或「圆角直线」，再沿墙脚中心线依次左键描点。贝塞尔模式可拖动选中点的橙色控制柄，拖过后该点切换到手动切线。圆角模式沿拐角描点，用「圆角半径」控制相切圆弧的大小，单位为 Unity 单位。半径为 `0` 时使用折角。两种模式均可拖动描点，中键平移，滚轮缩放。
3. 两种路径都可以勾选「启用门洞」。位置百分比从第一个描点沿墙脚计算，宽度用 Unity 单位，门洞两侧需保留墙段。烘焙时墙体和已启用的 2D 脚印碰撞在同一处断开。
4. 在「沿墙摆件」拖入 Prefab，输入摆件间距和占地半径。两种路径都从半个间距开始，沿墙脚等距摆放。遇到门洞会跳过侵入通道的摆放点。描点页的紫色点和短线标记位置和方向。
5. 切到「成品预览」。调节墙顶抬高、墙厚、顶部偏移和顶面／侧面色。墙面可以使用独立的贴图、Sprite 或自定义材质。平铺尺寸控制一张贴图覆盖的墙面长度和高度。
6. 用「另存草稿」保留下次可编辑的描点。用「烘焙到场景」生成场景对象及 Mesh 资产，然后保存场景。普通 MeshRenderer 使用「排序层」和「层内顺序」与 Sprite 排序。启用「添加 2D 脚印碰撞」会沿墙脚生成 PolygonCollider2D。

## 墙体样式预设

- 调好墙高、墙厚、颜色、贴图和摆件间距后，点击「另存预设」创建可复用的 `.asset`。也可选中已有预设，点击「更新预设」把当前外观保存到该资产。
- 在任意贝塞尔或圆角直线草稿里选择样式资产，再点「套用预设」。套用会复制样式值，可撤销。描点、控制柄、路径模式、闭环和门洞均保存在各自的草稿中。
- 勾选「独立顶面贴图」分别选择顶面与侧面的 Texture2D 或 Sprite。留空的一面仅使用该面的颜色。取消勾选时，整面墙共用一张贴图。使用自定义材质时，贴图由该材质决定。
- 预设也可保存摆件 Prefab、间距和靠近门洞时使用的占地半径。

## 首尾闭合与接墙

- 想画花坛或围墙时，在贝塞尔曲线或圆角直线模式勾选「首尾闭合」。至少画三个不同的描点，编辑器会连接最后一个点和第一个点。烘焙后的 2D 碰撞沿墙围成一圈，围墙内部保留空间。
- 想接两段开放墙时，打开第一段的草稿，再在「接墙」选择第二段的草稿。蓝色虚线显示接入段的描点。设置吸附距离，可自动选最近的端点，也可分别指定起点或终点。两段墙的场景 Z 坐标需一致。
- 点击「吸附并接墙」。接入端点吸附到当前端点，其余接入点保留原场景位置。合并结果使用当前草稿的路径类型和样式，门洞位置百分比按合并后的路径长度计算。可撤销，也可以另存合并草稿并烘焙成一面连续的墙。
- 闭环可以开门洞。调整门洞位置时，缺口需避开路径起点。闭环摆件会把间距均匀分给整圈，使首尾间距一致。

## 自定义柱子或灯笼

- 将素材保存为 Project 面板里的 **Prefab**。例如，把透明 PNG 导入为 `Sprite (2D and UI)`，挂到 Prefab 子节点的 SpriteRenderer。示例中可打开 `Assets/BezierWallDemo/RoundedWall/Terrace Brass Lantern.prefab` 查看结构。
- 根节点原点对齐希望落在墙脚上的位置，通常是底座中心。素材放在 XY 平面，根节点的本地 **+X** 用作朝前方向。烘焙时，根节点绕 Z 轴对齐墙线切线，并沿用 Prefab 的缩放。美术朝向需要补偿时，在子节点上调整。
- 如需实体柱子，可在 Prefab 内加 Collider2D。将「摆件占地半径」设为缩放后从根节点到图像或碰撞最远边缘的 XY 距离，以较远者为准。工具用这个半径给门洞留空。
- 烘焙出来的摆件是墙对象下的 Prefab 实例。摆件根节点按墙体的排序层显示，并排在墙体前方。多层图片可在 Prefab 子节点中设置相对排序。

## 场景约定

- 墙脚在 XY 平面，墙顶沿画面向上抬起并略微左右偏移。相机位于负 Z，向正 Z 看，使用正交投影。
- 草稿和烘焙结果各自保存。在已保存场景中，可关联草稿和场景墙。后续选中墙对象，打开关联草稿并点击「更新选中墙」，即可原位更新且支持撤销。「烘焙到场景」用于创建新墙。旧草稿默认使用贝塞尔模式，切换模式会保留描点和手动控制柄。
- 同一面圆角墙的所有转角共用一个半径。半径过大时，编辑器显示当前路径的上限。圆角半径需大于墙厚的一半，墙厚也会影响急转角能否生成。
- 推荐沿开口曲线描点，避免墙脚交叉。在急弯处可缩小墙厚或拉开控制点。单段烘焙墙使用同一排序层和顺序，如需让同一个角色穿插在不同墙段前后，可以按遮挡关系分段烘焙。
- 默认材质使用顶面和侧面的顶点色。自定义材质需要读取顶点色才能使用这两个颜色。
