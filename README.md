# BezierWall2D

Unity 2022.3.62f2 的卡通薄墙编辑器，用于正交相机下的俯角 2D 场景。

## 试用示例

1. 在 Unity Hub 里添加此工程，使用 Unity 2022.3.62f2 打开。
2. 在 Project 窗口打开 `Assets/BezierWallDemo` 下的示例场景，在 Game 视图查看完成的弯墙。
3. 双击同目录的草稿 `.asset`，查看参考图、已有描点和贝塞尔路径。

## 从素材开始

1. 打开 **Tools → 2D 弧形墙编辑器**，把 `Texture2D` 或 `Sprite` 拖到「描点底图」。底图宽度以 Unity 单位计，高度按图片比例计算。
2. 在「描点」页沿墙脚中心线依次左键点击。拖动描点可调整位置，拖动选中点的橙色控制柄可调整贝塞尔切线。拖过控制柄后，该点切换到手动切线。中键平移，滚轮缩放。
3. 切到「成品预览」。调节墙顶抬高、墙厚、顶部偏移和顶面／侧面色。墙面可以使用独立的贴图、Sprite 或自定义材质。平铺尺寸控制一张贴图覆盖的墙面长度和高度。
4. 用「另存草稿」保留下次可编辑的描点。用「烘焙到场景」生成场景对象及 Mesh 资产，然后保存场景。普通 MeshRenderer 使用「排序层」和「层内顺序」与 Sprite 排序。启用「添加 2D 脚印碰撞」会沿墙脚生成 PolygonCollider2D。

## 场景约定

- 墙脚在 XY 平面，墙顶沿画面向上抬起并略微左右偏移。相机位于负 Z，向正 Z 看，使用正交投影。
- 草稿和烘焙结果各自保存。修改草稿后重新烘焙会生成新的墙对象及资产。
- 推荐沿开口曲线描点，避免墙脚交叉。在急弯处可缩小墙厚或拉开控制点。单段烘焙墙使用同一排序层和顺序，如需让同一个角色穿插在不同墙段前后，可以按遮挡关系分段烘焙。
- 默认材质使用顶面和侧面的顶点色。自定义材质需要读取顶点色才能使用这两个颜色。
