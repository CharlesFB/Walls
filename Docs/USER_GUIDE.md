# BezierWall2D 使用说明

BezierWall2D 是 Unity 2022.3.62f2 的俯角 2D 墙体工具。你可以沿参考图描出墙脚，编辑贝塞尔曲线或圆角直线，设置门洞、摆件和贴图，再烘焙成场景里的墙体、材质和可选的 2D 碰撞体。

## 先试用示例

1. 在 Unity Hub 添加现有的 `BezierWall2D` 工程，用 Unity **2022.3.62f2** 打开。
2. 在 Project 面板双击示例场景，切换到 Game 视图查看。示例相机已经设置为正交投影。
3. 回到 Project 面板，双击示例草稿 `.asset`，即可在墙体编辑器查看描点和参数。试改参数后，可以用「另存草稿」制作自己的副本。

- 花园示例适合看贝塞尔弧线和控制柄。[花园场景](<../Assets/BezierWallDemo/Garden Demo.unity>) · [花园墙草稿](<../Assets/BezierWallDemo/Garden Wall Layout.asset>)
- 露台示例包含圆角直线墙、可通行的门洞、沿墙摆放的黄铜灯笼和闭环花坛。[露台场景](<../Assets/BezierWallDemo/RoundedWall/Terrace Demo.unity>) · [露台墙草稿](<../Assets/BezierWallDemo/RoundedWall/Terrace Wall Layout.asset>) · [花坛草稿](<../Assets/BezierWallDemo/RoundedWall/Terrace Flower Bed Layout.asset>)
- 露台下方用同一条路径对比砖墙和矮石墙。打开共享草稿，在「墙体样式」分别套用两套预设，再切到「成品预览」。[共享路径草稿](<../Assets/BezierWallDemo/RoundedWall/Style Comparison/Comparison Path Layout.asset>) · [砖墙预设](<../Assets/BezierWallDemo/RoundedWall/Style Comparison/Brick Wall Style.asset>) · [矮石墙预设](<../Assets/BezierWallDemo/RoundedWall/Style Comparison/Low Stone Wall Style.asset>)

## 从参考图开始画墙

1. 菜单打开 **Tools → 2D 弧形墙编辑器**，点击「新草稿」。
2. 把 Project 面板中的 **Texture2D 或 Sprite** 拖到「描点底图」的「Texture / Sprite」。用「底图中心」定位，用「底图宽度」指定它覆盖的 Unity 单位数，高度会随图片比例变化。用「不透明度」调淡底图。空白画布也可以直接描点。
3. 在「墙线路径」选择路径类型，然后在「描点」页沿墙脚**中心线**按顺序左键点击。点击已有点可以选中，拖动点会移动它。开放墙至少需要两个描点。
4. 用滚轮缩放，中键拖动平移。「适配视图」可以重新框住底图和墙线。画布获得焦点时，可按 Delete 或 Backspace 删除选中点，也可以点「删除选中描点」。
5. 切到「成品预览」检查墙体。保存前可回到「描点」继续调整。

### 选择路径类型

- **贝塞尔曲线**适合连续弧形。新增点默认使用「自动切线」。选中描点后，拖动橙色控制柄可调整弯曲方向和幅度，该点会切到手动切线。也可在「选中描点」里重新打开「自动切线」，或填写入、出控制柄偏移。需要更细的轮廓时提高「每段曲线细分」。
- **圆角直线**适合院墙、平台或花坛。沿直线的拐角描点，调整「圆角半径」即可让转角变圆。同一面墙共用一个半径，按墙脚中心线用 Unity 单位度量。半径为 `0` 时使用折角，用「每 90° 弧段细分」控制弧段精度。
- **首尾闭合**适合花坛和围栏。至少放三个不同描点，再勾选「首尾闭合」。系统自动连接最后一个点和第一个点，首点只需放一次。烘焙碰撞后，围边能够阻挡，围合区域仍是中空的。

### 把两段开放墙接起来

1. 先分别保存两段墙的草稿，确认它们的「场景位置」使用相同的 Z 值。
2. 打开要保留其样式的一段，在左侧「接墙」选择「接入草稿」。蓝色虚线显示接入段的描点。
3. 「当前墙端点」和「接入墙端点」都可以选「自动选最近端点」，也可以手动指定「起点」或「终点」。「吸附距离」以 Unity 单位计，控制两端点相距多远时允许合并。
4. 点击「吸附并接墙」。选中的接入端点吸附到当前端点，其余接入点保留原场景位置。合并后的路径类型和样式沿用当前草稿，门洞百分比按合并后的整条路径计算。
5. 预览后选择「另存草稿」保存拼接结果，或用「更新草稿」保存到当前草稿，再将合并结果烘焙成一面连续的墙。

## 设置外观和样式

- **墙顶抬高**控制墙的立体高度，**墙厚**控制墙脚的宽度，**墙顶偏移比例**调整顶面向左或向右偏移的程度。
- 分别用「顶面色」和「侧面色」调色。把 Texture2D 或 Sprite 拖到「墙面贴图」，可让整面墙使用这张贴图。勾选「独立顶面贴图」后，分别指定「侧面贴图」和「顶面贴图」。留空的一面只显示这一面的颜色。
- 「贴图平铺尺寸」用 Unity 单位设置一张贴图覆盖的尺寸。X 对应沿墙路径的长度，Y 对应侧面高度或顶面宽度。比如 X 填 `1`，同一张贴图每隔约一个 Unity 单位沿墙重复。
- 若选用「自定义材质」，贴图和着色由该材质控制。想使用工具自带的分面调色和平铺，清空自定义材质后在工具里选择颜色和贴图。

### 保存和套用预设

1. 调好墙高、墙厚、顶面与侧面的颜色和贴图，以及摆件 Prefab、间距和占地半径。
2. 在「墙体样式」点击「另存预设」，保存为新的样式 `.asset`。已有预设可选中后点击「更新预设」，将当前外观写入该资产。
3. 在另一面墙的「样式预设」选择该资产，点击「套用预设」。外观会复制到当前草稿，描点、控制柄、路径类型、闭环和门洞继续使用当前草稿的设置。变更满意后再保存草稿和烘焙。

## 设置门洞与沿墙摆件

### 门洞

1. 在「墙线路径」勾选「启用门洞」。每面墙可以配置一个门洞。
2. 「门洞位置 (%)」表示门洞中心沿墙脚路径的百分比，从路径起点开始算。用「门洞宽度」输入沿墙脚量出的 Unity 单位数。两侧都要留出墙段，闭环的门洞需避开路径起点。
3. 在「描点」和「成品预览」检查缺口。勾选「添加 2D 脚印碰撞」后再烘焙，网格与碰撞会在同一处断开。露台示例的位置为 `37.3%`，宽度为 `1.28`。

### 自定义柱子或灯笼

1. 准备一个 Project 面板里的 **Prefab 资产**。使用图片时，可先把透明 PNG 导入为 `Sprite (2D and UI)`，把 Sprite 放到 Prefab 的 SpriteRenderer 上。
2. 将 Prefab 根节点原点设在希望落到墙脚的位置，一般用底座中心。素材放在 XY 平面，本地 **+X** 作为朝前方向。工具绕 Z 轴对齐墙线切线，并保留 Prefab 的缩放。图片朝向可在 Prefab 子节点上调整。
3. 在「沿墙摆件」拖入「柱子 / 灯笼 Prefab」。用「摆件间距」控制沿墙的距离。开放墙从半个间距开始摆放，闭环会均匀分配整圈间距。
4. 「摆件占地半径」填写缩放后从根节点到图像或 Collider2D 最远边缘的 XY 距离，以两者中较远的一边为准。工具按这个范围让门洞留空。描点页的紫色点和短线分别表示位置和朝向。
5. 烘焙后，在墙对象下面的「沿墙摆件」容器查看 Prefab 实例。它们保留源 Prefab 链接。可以打开示例素材检查结构。[黄铜灯笼 Prefab](<../Assets/BezierWallDemo/RoundedWall/Terrace Brass Lantern.prefab>)

## 保存草稿并烘焙到场景

1. 点击「另存草稿」保存新的可编辑 `.asset`，或点击「更新草稿」保存当前已打开的草稿。切换草稿前先保存当前修改。以后可双击草稿继续描点。
2. 在「场景输出」设置「场景位置」「排序层」和「层内顺序」。墙脚在场景 XY 平面，正交相机放在负 Z 侧朝正 Z 看。想让墙阻挡角色时，勾选「添加 2D 脚印碰撞」。
3. 确认「成品预览」后点击「烘焙到场景」，在 Project 的 `Assets` 目录中为输出 Mesh 选择新的 `.asset` 文件名。工具会在当前场景创建墙对象，挂上 MeshFilter、MeshRenderer，以及按需添加的 PolygonCollider2D 和摆件。生成的默认材质随 Mesh 资产保存。
4. 保存 Unity 场景。草稿用于继续编辑，Mesh 和场景墙用于显示与碰撞。

## 关联草稿与原位更新

- **试用露台里的关联墙。** 打开露台示例，在 Hierarchy 选择 `Rounded Terrace Wall`。打开墙体编辑器，在「选中墙体」点击「打开关联草稿」。可以改描点、门洞宽度或套用砖墙与矮石墙预设。
- **更新现有墙。** 保持原墙被选中，点击编辑器底部的「更新选中墙」。墙对象、父子关系、位置和排序保持原样，网格、门洞碰撞和生成的摆件一起更新。这次更新支持 Unity 的撤销和重做。手工添加的组件和子节点以及手动指定的自定义材质会保留。
- **给自己的墙建立关联。** 在已保存的场景里从一份已保存草稿烘焙新墙，会自动关联。要关联之前烘焙的墙，先打开对应的草稿，选中该墙并点击「关联选中墙」。旧墙的网格须与对应草稿的结果匹配。
- **让改动跨重开保留。** 原位更新使用窗口中当前的草稿参数。确认后用「更新草稿」保存参数，并保存 Unity 场景。一个草稿可以关联多面墙，按钮只更新当前选中的墙。
- **共享输出。** 若网格或生成材质还被其他对象引用，更新会给当前墙分配独立资产。撤销会恢复原引用，分离出来的资产可在 Project 面板管理。

## 常见问题

- **圆角半径超出上限。** 缩小半径，或拉长拐角之间的直线段。若提示内侧折叠，可减小墙厚或放宽弧度。
- **门洞无法生成。** 缩小宽度或把中心移向有效路段，确保两端都有墙。闭环的门洞需要绕开首尾接合处。
- **门洞附近漏摆或挡路。** 核对 Prefab 的缩放和占地半径。门洞边缘会按填写的半径跳过摆放点。若提示候选位置过多，增大间距。
- **接墙距离超限。** 确认当前墙和接入墙的场景位置与选中的起终点，再移动端点或适当提高「吸附距离」。两个草稿都要使用开放路径。
- **贴图看不出变化。** 检查是否正在使用自定义材质。若要单独指定顶面贴图，确认「独立顶面贴图」已勾选，并检查两面的颜色和贴图平铺尺寸。
- **墙与角色遮挡顺序不对。** 先检查墙体和 Sprite 的排序层及层内顺序。若一长段墙需要在不同位置有不同遮挡关系，可以按关卡需要分段烘焙并分别排序。
